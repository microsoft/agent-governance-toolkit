# ACS alpha.4 dependency update

AGT updates its four direct `agent-control-spec` dependencies from
`=0.4.0-alpha.3` to `=0.4.0-alpha.4`. `agent-hooks-sdk` stays at
`=0.1.0-alpha.5`. The policy-engine, standalone Rust and coding-agent
workspaces use the same pair.

## Source and provenance

The crates.io artifact was published September 26, 2026 at 21:09:54 UTC.
Its trusted-publishing record names `responsibleai/agent-control-spec`,
GitHub Actions run `36271891481`, and commit
`e56d0050c5c1f462be6bde3b389e56ae4f04fdc8`.
The registry checksum, recorded in each consumer lockfile, is
`ce7cef7009046fda4752cf68911b6fa4076b6a7dcb5f6e0ef629b45dab7006f8`.

The seven-day window ends October 3 at 21:09:54 UTC. The maintainer authorized
local implementation and validation before then. This change does not alter
the scanner or bypass the CI gate.

## Dependency changes

Alpha.4 replaces the engine's archived `serde_yaml` and `unsafe-libyaml` path
with `serde-saphyr`. The policy workspace's opt-in Regorus graph moves from
0.11.0 to 0.12.0 and retains `yaml_serde` and `libyaml-rs` for YAML builtins.
This is not a claim that the whole graph is free of YAML native code.

Cargo regenerated all three lockfiles. Every newly resolved registry version
was checked against its crates.io publication timestamp on October 3. Only
the selected ACS release was inside the seven-day window. Existing unrelated
pins were retained, including `ureq` 3.4.0 and `ureq-proto` 0.6.1.

## Runtime changes

The update supports both upstream manifest contracts while preserving the
legacy host APIs and explicit OPA backend. It restores pinned bundle and
prompt URLs, passes download limits to default dispatchers, and retains
upstream provenance through typed manifest construction.
`system_prompt_file` remains unsupported.

The [retarget guide](https://github.com/microsoft/agent-governance-toolkit/blob/main/policy-engine/docs/acs-retarget.md) records the
remaining compatibility restrictions and package publication order.
This change does not publish any package or enable bundled annotators by
default.
